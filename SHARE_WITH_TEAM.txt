Oi pessoal! 👋

Desenvolvemos uma ferramenta nova: **🎯 Hawkeye**

Simples: ela diz se uma vulnerabilidade no seu código é **realmente explorável** ou só um falso positivo.

Lema: **Um tiro, um alvo. Sem desperdício.**

Resultado: 80% menos alertas falsos, mais foco.

🚀 QUICK START (3 min):

```bash
git clone https://github.com/lucasvsantos591-hue/hawkeye.git
cd vra-project
npm install && npm run build

# Teste:
node dist/cli/index.js analyze . --level 2 --output analysis.json
node dist/cli/index.js report analysis.json --format html --ai-provider none
node dist/cli/index.js report analysis.json --format html --ai-provider none --output report.html
```
